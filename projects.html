VulnScan

Automated web vulnerability scanner with integrated nmap, nikto, and sqlmap engines. Features Flask dashboard for real-time scan monitoring, vulnerability classification system, and automated PDF report generation. Tested against DVWA and production environments with configurable scan profiles. https://github.com/torchiachristian/VulnScan

AD-Attack Toolkit

Active Directory penetration testing automation framework. Implements AS-REP Roasting, Kerberoasting, and Pass-the-Hash attacks with integrated Hashcat support. Features automated enumeration via ldap3/Impacket, credential dumping, and professional PDF reporting. Includes complete VirtualBox lab setup with Windows Server 2019 DC and Windows 10 clients. https://github.com/torchiachristian/AD-Attack-Toolkit

HomeNetMonitor

Real-time home network monitoring dashboard with device detection and anomaly alerts. Built with Python/Flask, implements packet sniffing (scapy), network scanning (nmap), bandwidth monitoring, and anomaly detection. Features live web dashboard with Chart.js graphs for traffic visualization and 7-day connection timeline. https://github.com/torchiachristian/HomeNetMonitor
